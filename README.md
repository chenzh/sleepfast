# Sleepfast

Sleepfast 是一个面向英文市场的助眠网站项目，目标是帮助用户**更快入睡**、**减少夜间清醒**、**提升整体睡眠质量**。

当前仓库已补齐一个可运行的前端项目骨架，用于继续推进网页端助眠 MVP。

## 当前产出

- `docs/business-plan.md`：标准商业计划
- `docs/competitor-research.md`：英文助眠网站竞品调研
- `docs/prd.md`：MVP 产品需求文档
- `src/`：基于 React + Vite 的网页端骨架

## 本地启动

```bash
npm install
npm run dev
```

默认开发地址：`http://localhost:5173`

## 本地构建

```bash
npm run build
```

## 当前建议方向

- 先做 **网页可直接体验** 的助眠产品，而不是先做重 App
- 首屏直接提供一键播放的助眠音频 / 白噪音 / 呼吸节奏体验
- 用 SEO 承接 `fall asleep fast`、`sleep sounds`、`sleep better`、`white noise for sleep` 等高意图流量
- 用免费体验 + 订阅升级的方式验证转化
