# Sleepfast PRD（V2）

## 1. 文档概述

### 1.1 文档目的
本文档为 Sleepfast 低成本复刻心潮风格 MVP 版本专属 PRD，用于明确首期最小可行产品的功能范围、视觉设计、交互规则、优先级及验收标准。

本次 MVP 严格遵循以下原则：
- 高用户热度
- 极低复刻成本
- 核心体验闭环
- 保留标志性唯美动态视觉体系
- 剔除高难度算法、硬件监测、复杂生物反馈功能

首期只保留用户最受欢迎、可快速落地的核心能力，兼顾产品颜值与实用性，支持 Sleepfast 快速上线并验证英文市场在睡眠与轻减压赛道的需求。

### 1.2 MVP 核心定位
Sleepfast 是一款面向年轻失眠、轻度焦虑用户的轻量化高颜值助眠与情绪放松工具。

产品以两条主线为核心：
- 沉浸式唯美动态视觉
- 轻量化音频疗愈

首期不做复杂生理检测，不做 AI 算法分析，只聚焦两大核心刚需：
- 快速入睡
- 短时放松减压

同时保留心潮式标志性视觉差异化，形成网页端可体验的首版闭环。

### 1.3 选型依据（功能 + 视觉双维度）
基于心潮用户热度、评论反馈、功能使用率、视觉口碑和开发复刻成本，当前 MVP 选择如下方向：

- 最高频使用功能：白噪音助眠、沉浸式睡眠音频、短时放松冥想
- 最出圈差异化设计：唯美动态视频背景、场景化沉浸式动效
- 最容易复刻能力：预制动态素材 + 音频播放 + 基础交互
- 最强留存抓手：免费音频资源、组合音效、定时关闭、沉浸式视觉体验

### 1.4 版本原则
- 只做核心刚需 + 标志性视觉，不做复杂高成本功能
- 保证体验闭环：打开站点 → 沉浸式视觉场景 → 选音频播放 → 放松入睡
- 开发轻量化：无 AI、无硬件调用、无复杂后台计算
- 动态背景优先采用预制视频素材或低成本网页动效实现
- 所有页面优先服务“立即体验”和“沉浸感统一”

## 2. MVP 整体功能与视觉范围

本次 MVP 保留心潮方向最核心的 4 个模块，覆盖功能与视觉两条主线。

### MVP 四大核心模块
1. 场景化唯美动态视频背景系统（P0）
2. 场景化白噪音助眠（P0）
3. 场景化短时放松冥想（P0）
4. 基础播放工具能力：定时关闭、收藏、组合音效、最近播放（P0）

目标不是做一个普通声音播放器，而是做一个具备明显视觉记忆点的 Sleepfast 网页 MVP。

## 3. 详细功能与视觉需求 PRD

## 3.1 模块一：场景化唯美动态视频背景系统（P0）

### 3.1.1 功能定义
这是 Sleepfast 的核心颜值差异化能力，用于区别于普通静态图片背景的助眠网站。

系统目标：
- 采用全屏沉浸式高清动态背景
- 不同助眠、放松场景自动匹配专属动态画面
- 形成视听一体的疗愈体验
- 成为用户感知最强、最容易传播的产品亮点

### 3.1.2 视觉设计核心规范
整体视觉应严格遵循以下方向：

- 风格：极简治愈、低饱和、柔光、慢速循环
- 调性：静谧、舒缓、不刺激、不炫技
- 画面节奏：慢、稳、连续、无缝、不抢注意力
- 使用场景：适合夜间使用，不可刺眼

核心视觉元素优先级：
- 流动云海
- 静谧海岸
- 林间光影
- 细雨朦胧
- 星空深空
- 微风枝叶

色彩体系：
- 薄荷蓝
- 浅雾灰
- 温柔白
- 低饱和青绿色

禁止项：
- 高饱和刺眼配色
- 强光闪烁
- 节奏过快的动效
- 明显卡顿或跳变

### 3.1.3 场景一一对应匹配规则
音频场景与动态背景必须强绑定，保持视听统一：

- 海浪 / 海岸音效 → 潮汐海岸、柔光海面动态背景
- 森林 / 鸟鸣音效 → 林间光影、微风枝叶动态背景
- 雨声 / 风雪音效 → 朦胧雨景、静谧风雪动态背景
- 深空 / 纯白噪音 → 星空云海、渐变柔光深空动态背景
- 冥想放松课程 → 极简柔光、静态粒子浮动、慢流云动态背景

### 3.1.4 交互规则
- 进入对应播放页面后自动切换匹配动态背景
- 用户无需手动设置背景
- 视频背景默认静音，仅作为视觉氛围层
- 支持后台播放；锁屏后动态画面暂停以节省功耗
- 播放控件与文字内容悬浮在动态背景上方
- 控件透明度、对比度和层级需适配夜间场景

### 3.1.5 验收标准
- 所有动态背景可无缝循环
- 无卡顿、无黑屏、无画面撕裂
- 场景与背景匹配准确
- 整体色调柔和，适合夜间使用
- UI 控件清晰，不被背景干扰

## 3.2 模块二：场景化白噪音助眠（P0）

### 3.2.1 功能定义
提供多场景、分类清晰的自然白噪音、环境音和睡眠疗愈音，解决用户入睡难、睡眠浅、环境嘈杂的问题。

这是 Sleepfast 的核心留存功能。

### 3.2.2 功能细分
分类体系：

#### 自然系列
- 雨声
- 森林
- 溪流
- 海浪
- 风雪
- 鸟鸣

#### 氛围系列
- 白噪音
- 低频放松
- 静谧深空
- 温柔书房

#### 治愈系列
- 轻音乐
- 钢琴
- 纯音
- 慢节奏疗愈

### 3.2.3 多音效组合播放
这是 MVP 需要保留的人气能力。

要求：
- 支持自由叠加 2-3 种音效
- 用户可组合出自己的助眠背景音
- 组合示例：雨声 + 钢琴 + 风声
- 各音轨支持独立音量调节

### 3.2.4 交互规则
- 点击音效即播放，再次点击暂停
- 支持后台播放与锁屏播放
- 播放界面保持极简，不出现破坏沉浸感的广告或弹窗
- 当前播放场景应同步切换对应动态背景

### 3.2.5 验收标准
- 所有音频播放流畅，无卡顿、无明显杂音
- 多音效叠加正常工作
- 每路音量调节实时生效
- 锁屏与后台续播正常

## 3.3 模块三：场景化短时放松冥想（P0）

### 3.3.1 功能定义
对标心潮式场景减压冥想，主打短时、碎片化、零基础的引导式音频。

目标是帮助用户在非睡眠场景下也能快速获得放松，兼顾拉新、传播与日间使用频次。

### 3.3.2 功能细分
全部采用纯音频引导，无需复杂视频课程。

首期课程：
- 极速放松（3 分钟）
- 考前 / 面试镇定（5 分钟）
- 情绪平复（8 分钟）
- 睡前放松（10 分钟）

### 3.3.3 交互规则
- 每个课程必须标注时长与适用场景
- 点击即播放
- 内容形式为人声引导 + 背景轻音乐
- 匹配专属静谧慢动态背景
- 冥想课程播放过程不可快进

### 3.3.4 验收标准
- 场景分类清晰
- 用户一眼能理解课程用途
- 音频人声清晰，配乐舒缓
- 进度条和播放逻辑正常

当前 Web MVP 已先收口为 `/sleep-breathing-exercise` 的 4-7-8 呼吸节奏器，用于补齐“短时放松/入睡前放松”最低体验闭环；当前已补上呼吸结束后的雨声 / 棕噪音一键承接入口，把“先放松再进声音场景”的路径直接接回主播放器；更完整的人声引导冥想课程仍待后续迭代。

当前 Web MVP 已进一步把 `/sleep-breathing-exercise` 反向接入 `/wake-up-at-3am` 与 `/mind-racing-at-night`，在问题场景页首屏播放器下直接给出“先做 4-7-8 呼吸再进声音”的桥接入口，先收口“问题页 → 放松重置 → 声音场景”的最低双向闭环。

当前 Web MVP 已把 `/sleep-breathing-exercise` 的呼吸后承接从 Rain / Brown 扩到 White / Ocean，覆盖“先放松 → 夜醒重启 / 更长一点的深度漂浮”两类常见后续路径，减少做完呼吸后还要回首页重新挑场景的断点。

当前 Web MVP 已把首页与工具页之间的 SEO 承接扩到 `/nap-calculator`，首屏即可输入 nap 开始时间并得到 20 / 30 / 90 分钟结束时间，同时桥接 `/sleep-breathing-exercise` 与 `/rain-sounds-for-sleep`，先补齐 daytime recovery 到核心声音体验的最小闭环。

当前 Web MVP 已新增 `/jet-lag-calculator`，首屏即可输入落地后次日的本地起床时间并得到第一晚 bedtime 建议，同时桥接 `/sleep-breathing-exercise` 与 `/ocean-sounds-for-sleep`，先补齐 travel recovery 到核心声音体验的最小闭环。

## 3.4 模块四：基础工具能力（P0）

该模块用于补齐体验闭环，是 MVP 的必备配套能力。

### 3.4.1 定时关闭
要求：
- 支持 10min / 20min / 30min / 60min / 自定义时间
- 定时结束后音频平滑淡出
- 动态背景同步渐隐退出

当前 Web MVP 已补上“计时结束时平滑淡出”的最低实现，先解决浏览器端定时截止时的硬停感；背景渐隐仍待后续迭代补齐。

当前 Web MVP 已先收口为 10 / 20 / 30 / 45 / 60 分钟预设，并补上 1-180 分钟自定义 timer 输入，用于覆盖 nap、longer drift、travel recovery 等非标准时长场景；计时结束后的平滑淡出保留为默认收口方式。

### 3.4.2 收藏功能
要求：
- 支持收藏任意白噪音或冥想课程
- 收藏内容保留对应场景背景信息
- 提供独立“我的收藏”页面或入口

当前 Web MVP 已在首页与白噪音工具页补上“Save this sound”入口，并把收藏落到浏览器本地存储；先收口“保存常用声音 + 下次一键重播”的最低闭环，独立收藏页仍待后续迭代。

### 3.4.3 最近播放
要求：
- 自动记录近期播放内容
- 支持一键重播
- 尽量恢复对应的视听场景

当前 Web MVP 已记录最近播放声音，并在首页、白噪音工具页、`/fall-asleep-fast` 与 `/wake-up-at-3am` 提供一键重播入口；当前先恢复对应声音与基础计时器场景，后续再补更完整的场景背景恢复。

## 4. MVP 明确不做的功能

以下能力全部排除在首期 MVP 之外：

- 摄像头 AI 心率 / 情绪监测
- 生物反馈动态调节
- 深度睡眠数据报告
- 睡眠评分
- 社区、打卡、积分、会员体系
- 超长专项疗愈课程
- 高成本专栏型内容体系

判断标准：凡是增加高复刻成本、拉长开发周期、不能显著提升首屏闭环的功能，一律延后。

## 6. 优先级总表

### P0：必须优先实现
- 场景化唯美动态视频背景系统
- 场景化白噪音 + 多音组合播放
- 场景化短时冥想放松课程
- 定时关闭 + 收藏 + 最近播放

优先级判断逻辑：
- 是否影响用户第一眼感知
- 是否影响首屏立即体验
- 是否影响留存与复用
- 是否能低成本快速上线

## 7. MVP 上线核心价值

### 7.1 视觉与体验差异化
Sleepfast 的首期价值不只是“能播放声音”，而是同时保留：
- 核心音频能力
- 标志性唯美动态视觉

形成高辨识度的网页助眠体验。

### 7.2 低成本落地
通过预制动态素材、网页播放能力和基础交互，即可实现高颜值 MVP，无需 AI、无需硬件、无需重后台。

### 7.3 双重差异化
Sleepfast 的差异化来自两层：
- 功能差异：场景减压 + 组合音效
- 视觉差异：沉浸式唯美动态背景

### 7.4 可快速迭代
在 MVP 底座稳定后，二期可继续叠加：
- 更丰富的音频库
- 会员与订阅体系
- 个性化推荐
- 数据报告与更深层留存能力

---

## 8. 当前版本落地策略

当前 Sleepfast 不再继续走“普通助眠工具页集合”的窄路线，而是进入“心潮方向的网页低成本复刻”路线。

这意味着后续迭代优先级调整为：
- 先补强沉浸式动态视觉系统
- 再补白噪音、多音组合与场景绑定
- 再补短时冥想与个人资产页
- 继续保留 SEO 工具页，但它们要服务于核心沉浸式播放体验，而不是独立生长成纯内容页

---

## 9. 研发执行要求

后续开发必须遵循以下规则：
- 每次迭代优先形成可见、可体验的闭环
- 不做纯文案层面的虚假推进
- 优先推进动态背景、音频体验、播放工具三件事
- 页面视觉和交互必须围绕“夜间使用”优化
- 所有新增页面都应能导向播放详情页或直接触发体验

---

## 10. MVP 验收总标准

只要同时满足以下四点，即视为首版方向正确：
- 用户进入站点后能快速感知到高辨识度视觉氛围
- 用户能在极短路径内开始音频体验
- 用户能理解不同场景与不同声音的对应关系
- 用户愿意重复使用或收藏常用场景

这是 Sleepfast 当前阶段最重要的产品文档基线。
